# Security

Provodnik runs tools (git, curl, 7-Zip), downloads files and writes into your GAMMA folder, so security reports matter.

If you find a vulnerability, please **don't open a public issue**. Report it privately through
[Security → Report a vulnerability](https://github.com/ruan-luidy/Provodnik/security/advisories/new) on this
repository. Only the latest release gets fixes.

Every release lists the SHA-256 of `Provodnik.exe`; check it with `Get-FileHash .\Provodnik.exe` before running a copy
you didn't download from the [releases page](https://github.com/ruan-luidy/Provodnik/releases).
